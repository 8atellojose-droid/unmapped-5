Provenance Tier System

Every metric on a recommendation card is tagged with one of these tiers, so the source of each value is visible at a glance — direct API, official fallback, published benchmark, or modeled proxy.

REAL · World Bank API
Live World Bank API pull (NEET / Internet / Literacy)
OFFICIAL · ILOSTAT (USD)
Direct ILOSTAT major-group earnings in U.S. dollars
OFFICIAL FALLBACK
Official ILOSTAT pull but no direct USD series — uses PPP$ or skill-level fallback
BENCHMARK · Frey-Osborne
Published academic benchmark (Frey & Osborne 2017 automation probability)
LEGACY PROXY
Modeled planning estimate, kept only as a fallback when no API series matches

End-to-End Data Flow

1 · Raw input
raw_youth_profiles.csv or live custom-profile form (Tab 1).
2 · Normalize
extract_normalized_skills + ISCO-08 role mapping + semantic assist.
3 · Score
Constraint-weighted confidence (data-driven rules in constraint_weights.csv).
4 · Recommend
recommend_opportunities joins econ signals + AI Readiness + catalog pathways.
5 · Render
Per-card REAL/PROXY/BENCHMARK badges + t()-localized copy across 7 languages.
